The backend framework that shows its work.

Tsir is a strictly typed, backend-only TypeScript framework for Bun and Cloudflare Workers. Decorator routing compiled into an immutable route table, constructor injection with no global container, Drizzle on D1 (default) or PostgreSQL, versioned AES-256-GCM column encryption that fails closed, and first-class Workers and AWS Lambda deploy units. REST, gRPC, SOAP and WebSocket are part of the same model, not bolt-ons.

$ make install && make dev

What exists today: the Makefile and dev server, the Phase 1 core — @tsir/container, @tsir/config, @tsir/core, @tsir/validate (on top of Zod), @tsir/testing — the tsir CLI, and a generated dist/ that boots, tree-shakes and bundles for Workers and Lambda. There is an HTTP surface as of Phase 2, a D1 driver and Postgres as of Phase 3, encryption as of Phase 4, and a deploy adapter and per-unit emitter as of Phase 6 — but nothing has been deployed to Workers or Lambda, so a bundle on disk is not a deployment guarantee. No package is published to npm, and the only numbers on this page are the measured bundle sizes below — not benchmarks. Each card links to the design document that governs it and is tagged with the phase that will build it.

Drizzle as the ORM, untouched. Tsir adds a driver contract with declared capabilities, atomic batch() writes, health and bounded disposal. Why one package, four entrypoints

Sixty percent of interop code is the hard, shared part: deadlines, cancellation, retry budgets, credentials, tracing, error normalization. Four packages would mean four implementations — or a fifth package that does the work anyway.

  • /soap compiled from WSDL at build time — no runtime schema fetches
  • gRPC on Bun and Lambda; Workers documented as unsupported, not faked
  • WebSocket frames validated against a discriminated union

What Tsir refuses to do

Four rules that survive every refactor.

No global service locator

Dependencies arrive through constructors from a container built at bootstrap. There is no well-known symbol for a compromised dependency to reach.

No reflection on the request path

Routes, providers, listeners and jobs compile into immutable registries. Production boot consumes data; it does not scan classes.

No silent crypto fallbacks

Every encrypted value carries a versioned envelope and a key id. Missing keys, tampered tags, malformed input — all fail closed, loudly.

No ambient transactions

A transaction is a scoped handle you pass explicitly. No hidden context that silently enrolls queries you did not intend to run.
